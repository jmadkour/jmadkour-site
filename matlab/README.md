# Scripts MATLAB / Octave

Scripts d'accompagnement du cours [Outils — MATLAB / Octave](https://jmadkour.org/cours/matlab/premiers-pas.html)
du site [jmadkour.org](https://jmadkour.org).

Chaque fichier correspond a un bloc de code du chapitre 1. Les boutons
« Ouvrir dans MATLAB Online » du site pointent directement sur ces fichiers :
MATLAB Online clone le depot dans votre MATLAB Drive et ouvre le script demande.

Un compte MathWorks gratuit suffit. Les scripts sont egalement compatibles
avec GNU Octave, sans aucune modification.
