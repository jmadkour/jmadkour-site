# Scripts MATLAB / Octave

Scripts d'accompagnement du cours [Informatique — MATLAB](https://jmadkour.org/cours/matlab/index.html)
du site [jmadkour.org](https://jmadkour.org).

Un fichier par bloc de code. Les boutons « Ouvrir dans MATLAB Online » du site
pointent sur ces fichiers : MATLAB Online clone le depot dans votre MATLAB Drive
et ouvre le script demande. Un compte MathWorks gratuit suffit.

Les scripts fonctionnent tels quels dans GNU Octave, sans modification.
