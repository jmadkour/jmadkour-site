Le problème, et sa solution

Ce qu’on cherche

Le programme, rappelé

Trouver la direction de l’espace sur laquelle la projection du nuage conserve le maximum d’inertie.

C’est le problème du photographe, énoncé mathématiquement.

Pourquoi le chapitre 6 l’a rendu possible

L’inertie mesure l’information ; une projection la coupe en une part conservée et une part perdue. Maximiser la première, c’est minimiser la seconde : le meilleur axe est celui qui écrase le moins le nuage.

Le nuage réel, et ce qu’on attend d’un axe

Faire tourner l’axe

L’expérience de pensée

Imaginons un axe passant par le centre du nuage, qu’on fait pivoter.

Pour chaque position, on projette les points et on mesure la dispersion des projections : grande quand l’axe suit l’allongement du nuage, petite quand il lui est perpendiculaire.

Il existe donc une position optimale, et c’est elle qu’on retient.

Sur les cinq clients réduits

Au chapitre 6, l’axe de l’accueil conservait 1, la diagonale 1{,}9, l’anti-diagonale 0{,}1. Faisons maintenant tourner l’axe degré par degré.

L’inertie projetée, angle par angle

Ce que la courbe montre

L’inertie projetée monte de 1 (l’accueil) à \mathbf{1{,}9} à 45°, redescend à 1 (la fidélité), puis à 0{,}1 à 135°. Le maximum est unique : c’est la diagonale.

La solution, à la main

L’inertie d’une direction quelconque

Une direction, une combinaison

Une direction du plan est un vecteur u = (a \,;\, b) de longueur 1 : a^2 + b^2 = 1.

Projeter le client i sur cette direction donne le nombre a\, z_{x,i} + b\, z_{y,i}. L’inertie projetée est la variance de cette combinaison.

La formule du chapitre 3 fait le reste

I(u) = V(a\, z_x + b\, z_y) = a^2 \underbrace{V(z_x)}_{1} + b^2 \underbrace{V(z_y)}_{1} + 2ab\underbrace{\operatorname{cov}(z_x, z_y)}_{r = 0{,}9}

I(u) = a^2 + b^2 + 2ab \times 0{,}9 = 1 + 1{,}8\, ab

Le maximum, en trois lignes

Maximiser 1 + 1,8 ab sur les directions de longueur 1
  1. Comme (a - b)^2 \geq 0, on a 2ab \leq a^2 + b^2 = 1, donc ab \leq \frac{1}{2}.
  2. Donc I(u) \leq 1 + 0{,}9 = 1{,}9, avec égalité si et seulement si a = b.
  3. Avec a^2 + b^2 = 1 : a = b = \frac{1}{\sqrt 2} \approx 0{,}707. C’est la diagonale.
Et le minimum

De même (a + b)^2 \geq 0 donne ab \geq -\frac{1}{2}, donc I(u) \geq 1 - 0{,}9 = 0{,}1, atteint pour a = -b : l’anti-diagonale.

Ce que la démonstration révèle

Tout dépend de r

Le maximum vaut 1 + r et le minimum 1 - r. Plus les deux variables sont corrélées, plus le meilleur axe conserve d’inertie — et plus l’anti-diagonale en perd.

Si r = 0, toutes les directions donnent I(u) = 1 : aucune n’est meilleure qu’une autre.

Ce qui change avec p variables

Avec deux variables, l’astuce (a - b)^2 \geq 0 suffit. Avec huit, il faut chercher 8 coefficients sous la contrainte que leurs carrés somment à 1. Le chapitre 8 montre que la réponse est encore exacte et se calcule : elle s’appelle un vecteur propre.

Les composantes principales

Le premier axe

Première composante principale

La première composante principale est la direction qui maximise l’inertie projetée.

C’est la direction d’allongement maximal du nuage.

Sur le fil rouge

Les cinq clients sont presque alignés — r = 0{,}9. La direction d’allongement est donc la diagonale, celle qui monte de l’individu 1 vers l’individu 5.

Cet axe unique résume à lui seul l’essentiel du tableau : les clients se distinguent surtout par une satisfaction globale, qui fait varier ensemble l’accueil et la fidélité.

Les axes suivants

Les composantes suivantes

La deuxième composante est la direction qui maximise l’inertie restante, sous une contrainte : elle doit être orthogonale à la première.

Puis la troisième, orthogonale aux deux premières, et ainsi de suite jusqu’à p axes.

Pourquoi l’orthogonalité

Sans cette contrainte, le deuxième axe se placerait presque au même endroit que le premier : il redirait la même chose.

L’orthogonalité garantit que chaque nouvel axe apporte une information que les précédents n’avaient pas. Les composantes sont ainsi non corrélées entre elles, et l’inertie qu’elles portent s’additionne sans double compte.

Les deux axes des cinq clients

Dans le plan, le second axe est imposé

Il n’y a qu’une direction perpendiculaire à la diagonale : l’anti-diagonale, (a \,;\, b) = \left(\tfrac{1}{\sqrt 2} \,;\, -\tfrac{1}{\sqrt 2}\right). Elle porte les 0{,}1 restants.

Les nouvelles coordonnées

Les composantes C1 et C2 des cinq clients

C_1 = (z_x + z_y)/\sqrt 2 et C_2 = (z_x - z_y)/\sqrt 2 :

Client z_x z_y C_1 C_2
1 -1{,}414 -1{,}414 -2 0
2 -0{,}707 0 -0{,}5 -0{,}5
3 0 -0{,}707 -0{,}5 0{,}5
4 0{,}707 0{,}707 1 0
5 1{,}414 1{,}414 2 0

Trois vérifications

Variances et covariance des composantes

V(C_1) = \frac{4 + 0{,}25 + 0{,}25 + 1 + 4}{5} = \frac{9{,}5}{5} = 1{,}9

V(C_2) = \frac{0 + 0{,}25 + 0{,}25 + 0 + 0}{5} = \frac{0{,}5}{5} = 0{,}1

\operatorname{cov}(C_1, C_2) = \frac{0 + 0{,}25 - 0{,}25 + 0 + 0}{5} = 0

Trois propriétés à retenir
  1. Les axes sont hiérarchisés : le premier porte le plus d’inertie, puis le deuxième (1{,}9 > 0{,}1).
  2. Ils sont orthogonaux, et les composantes non corrélées (\operatorname{cov} = 0).
  3. Les inerties portées s’additionnent et redonnent l’inertie totale (1{,}9 + 0{,}1 = 2).

Le changement de regard

De variables observées à variables construites

Ce qu’est une composante

Une composante principale est une combinaison linéaire des variables de départ : C_1 = a_1 z_1 + a_2 z_2 + \dots + a_p z_p

C’est une variable nouvelle, qu’on n’a pas mesurée mais construite.

Ce que cela donne en gestion

Sur un fichier de satisfaction, le premier axe combine souvent positivement tous les critères : c’est un niveau général de satisfaction, que personne n’a mesuré directement.

Le deuxième oppose fréquemment deux familles de critères. Il mesure alors un arbitrage entre deux dimensions du jugement.

Ce que disent ces coefficients

C1 : presque une moyenne

Les huit coefficients sont positifs et voisins de 1/\sqrt 8 = 0{,}354, le poids d’une moyenne. C_1 est le niveau général de satisfaction ; sa corrélation avec la note moyenne d’un client vaut 0{,}9997. Le prix y pèse un peu moins, l’agencement et la propreté un peu plus.

C2 : l’offre contre le service

Les coefficients sont positifs pour le prix, le choix, la qualité, l’agencement, négatifs pour la rapidité, le conseil, l’accueil. C_2 oppose les clients qui louent l’offre à ceux qui louent le service, à niveau général égal.

Ce qu’aucune moyenne ne pouvait dire

Sur C_1, les deux clients sont confondus : même niveau, légèrement au-dessus de l’ensemble. Sur C_2, ils sont aux antipodes : le client 36 du côté du service, le client 246 du côté de l’offre. Deux nombres suffisent à résumer ce que huit notes disaient — l’exercice 2 du chapitre 1 l’annonçait.

La nuance à ne pas manquer

Une composante n’a pas de sens toute seule

Ces variables construites n’existaient pas dans le tableau. Rien ne garantit qu’elles aient un sens.

Les interpréter est un travail à part entière : il faut regarder quelles variables les composent — c’est le chapitre 10 — et connaître le domaine. Une composante mal nommée est une erreur durable.

Le piège sur nos données

Appeler C_2 « sensibilité au prix » serait faux : le prix n’est qu’une des quatre notes du côté positif. « L’offre contre le service » décrit ce que C_2 mesure vraiment.

Quand l’ACP est utile

La condition

Des variables corrélées

L’ACP n’apporte quelque chose que si les variables sont corrélées entre elles.

Si toutes les corrélations sont nulles, chaque variable porte une information propre : aucune réduction n’est possible, et tous les axes portent la même inertie.

Le contrôle préalable

D’où l’importance de la matrice des corrélations du chapitre 4 : elle se regarde avant de lancer l’analyse.

Une matrice de corrélations proches de zéro annonce que l’ACP ne servira à rien. Une matrice pleine de valeurs fortes annonce l’inverse — les variables se répètent, et l’on pourra les résumer.

Des notes liées, ou du bruit

Deux tableaux de 300 lignes et 8 colonnes

Sur les huit notes réelles, le premier axe porte 4{,}54 unités d’inertie sur 8. Sur huit variables indépendantes simulées, le meilleur axe n’en porte que 1{,}26, à peine plus qu’une variable seule : il n’y a rien à résumer.

Sur machine

Avec R

Faire tourner l’axe, de 15 en 15 degrés 
zx <- (c(8, 10, 12, 14, 16) - 12) / sqrt(8)
zy <- (c(4, 12, 8, 16, 20) - 12) / sqrt(32)
angle <- seq(0, 180, by = 15)
inertie <- sapply(angle * pi / 180, function(t)
  mean((cos(t) * zx + sin(t) * zy)^2))
round(setNames(inertie, angle), 3)
#     0    15    30    45    60    75    90   105   120
# 1.000 1.450 1.779 1.900 1.779 1.450 1.000 0.550 0.221
#   135   150   165   180
# 0.100 0.221 0.550 1.000
angle[which.max(inertie)]                    # [1] 45

Avec Python

La même expérience, en une ligne de calcul 
import numpy as np
zx = (np.array([8, 10, 12, 14, 16]) - 12) / np.sqrt(8)
zy = (np.array([4, 12, 8, 16, 20]) - 12) / np.sqrt(32)
angle = np.arange(0, 181, 15)
t = np.radians(angle)
p = np.outer(np.cos(t), zx) + np.outer(np.sin(t), zy)
inertie = (p ** 2).mean(axis=1)
print(inertie[:7].round(3))        # de 0 à 90 degrés
# [1.    1.45  1.779 1.9   1.779 1.45  1.   ]
print(angle[inertie.argmax()], inertie.max().round(3))   # 45 1.9
Une méthode qui ne passe pas à l’échelle

Essayer tous les angles marche dans le plan, pas dans un espace à huit dimensions : le chapitre 8 calcule les axes directement.

S’entraîner

Exercice 1 : une corrélation de 0,6

Deux notes moins liées

Deux notes réduites ont une corrélation r = 0{,}6.

  1. Écrire l’inertie projetée sur la direction (a \,;\, b).
  2. Quel est le meilleur axe ? Quelle inertie conserve-t-il, et quelle part ?
  3. Quelle inertie porte le second axe ?

Exercice 1 : solution

1,6 sur 2, soit 80 pour cent
  1. I(u) = a^2 + b^2 + 2ab \times 0{,}6 = 1 + 1{,}2\, ab.
  2. Le maximum est atteint pour a = b = 1/\sqrt 2 — encore la diagonale — et vaut 1 + 0{,}6 = 1{,}6, soit 80\,\% de l’inertie totale 2.
  3. L’anti-diagonale porte 1 - 0{,}6 = 0{,}4, soit 20\,\%. Moins de corrélation, moins de réduction possible : 80\,\% au lieu de 95\,\%.

Exercice 2 : calculer deux composantes

Quatre individus réduits

Quatre individus ont pour valeurs réduites (z_x ; z_y) : (1 ; 1), (1 ; -1), (-1 ; 1), (-1 ; -1).

  1. Calculer la corrélation entre z_x et z_y.
  2. Calculer C_1 = (z_x + z_y)/\sqrt 2 et C_2 = (z_x - z_y)/\sqrt 2, puis leurs variances.
  3. Que conclure ?

Exercice 2 : solution

Aucune direction privilégiée
  1. Produits z_x z_y : 1, -1, -1, 1, de somme nulle : r = 0.
  2. C_1 = 1{,}414 ; 0 ; 0 ; -1{,}414 et C_2 = 0 ; 1{,}414 ; -1{,}414 ; 0 : V(C_1) = V(C_2) = 4/4 = 1.
  3. Les deux axes portent chacun la moitié de l’inertie, exactement comme les variables d’origine. Le nuage est un carré, sans allongement : l’ACP n’a rien à résumer.

Exercice 3 : une corrélation négative

Prix et rapidité, liés en sens contraire

Deux notes réduites ont r = -0{,}5.

  1. Pour quelle direction l’inertie projetée est-elle maximale ? Que vaut-elle ?
  2. Interpréter la composante correspondante.

Exercice 3 : solution

Le meilleur axe est l’anti-diagonale
  1. I(u) = 1 + 2ab \times (-0{,}5) = 1 - ab. Elle est maximale quand ab est le plus négatif, soit ab = -\frac{1}{2} : a = -b = 1/\sqrt 2. L’inertie vaut 1{,}5, soit 75\,\%.
  2. C_1 = (z_x - z_y)/\sqrt 2 oppose les deux notes : un client haut sur C_1 juge bien la première et mal la seconde. Quand les variables varient en sens contraire, le premier axe est un arbitrage, non un niveau.

Ce qu’il faut retenir

Le résumé du chapitre

Six points
  1. La première composante est la direction qui maximise l’inertie projetée.
  2. Sur deux variables réduites, I(u) = 1 + 2ab\,r : le maximum 1 + r est atteint sur la diagonale — 1{,}9 pour nos clients.
  3. Les suivantes maximisent l’inertie restante, sous contrainte d’orthogonalité ; les composantes sont non corrélées.
  4. Les inerties s’additionnent : 1{,}9 + 0{,}1 = 2.
  5. Une composante est une combinaison linéaire des variables : sur le fichier réel, C_1 est le niveau général, C_2 l’offre contre le service.
  6. L’ACP n’est utile que si les variables sont corrélées : sur du bruit, le meilleur axe ne porte que 1{,}26 sur 8.
