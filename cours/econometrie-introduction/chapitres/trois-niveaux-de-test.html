Les trois niveaux de test

Diapositives Polycopié du chapitre Exercices corrigés Application interactive

Trois questions différentes

Ce qu’ils demandent

Le test global de Fisher

Le modèle sert-il à quelque chose

H_0 : \beta_1 = \beta_2 = \cdots = \beta_k = 0

F = \frac{\text{SCE}/k}{\text{SCR}/(n-k-1)} \;\sim\; \text{Fisher à } k \text{ et } n-k-1 \text{ degrés de liberté}

Sur le modèle M2

F = \frac{\text{SCE}/3}{\text{SCR}/496} = \frac{2\,166{,}0/3}{1\,209{,}1/496} = 296{,}19 \qquad p < 0{,}0001

On rejette : l’ensemble des variables explique significativement le salaire.

Ce que le F global vaut vraiment

C’est le test le moins informatif des trois

H_0 affirme que toutes les variables sont sans effet. Sur des données économiques réelles, cette hypothèse est presque toujours fausse — et donc presque toujours rejetée.

Un F significatif est un minimum, non un résultat. On ne publie pas un modèle sur la foi de son F.

Le lien avec le R^2

F = \frac{R^2/k}{(1-R^2)/(n-k-1)}

Les deux mesurent la même chose ; le F y ajoute seulement les degrés de liberté. En régression simple, F = t^2 : sur les cinq ménages, F = 9 = 3^2.

Démonstration : F en fonction du R^2, et F = t^2 en régression simple

En divisant le numérateur et le dénominateur de F par \text{SCT}, et comme \text{SCE}/\text{SCT} = R^2 et \text{SCR}/\text{SCT} = 1-R^2, F = \frac{\text{SCE}/k}{\text{SCR}/(n-k-1)} = \frac{R^2/k}{(1-R^2)/(n-k-1)}. Pour k = 1, on a \text{SCE} = \widehat{\beta}_1^{\,2}S_{xx} (chapitre 4) et \widehat{\sigma}_\varepsilon^2 = \text{SCR}/(n-2), donc F = \frac{\widehat{\beta}_1^{\,2}S_{xx}}{\widehat{\sigma}_\varepsilon^2} = \Big(\frac{\widehat{\beta}_1}{\widehat{\sigma}_\varepsilon/\sqrt{S_{xx}}}\Big)^2 = t^2. Sur les cinq ménages : F = 22{,}5/2{,}5 = 9 = 3^2.

∎

Le test global, sur les cinq ménages

Revenu et taille, deux degrés de liberté au dénominateur

F = \frac{\text{SCE}/2}{\text{SCR}/2} = \frac{25/2}{5/2} = 5 \qquad \text{seuil } F_{2\,;2} = 19{,}0 \qquad p = 0{,}17

Avec R^2 = 0{,}833, on ne rejette même pas l’hypothèse que rien n’explique la consommation.

Un R^2 élevé ne suffit pas

Par la formule : F = (0{,}833/2)/(0{,}167/2) = 5. Le R^2 est grand, mais il repose sur deux degrés de liberté. Le même R^2 sur 400 ménages donnerait un F de près de mille.

Les tests individuels

La question qu’ils posent

Une variable, les autres étant présentes

H_0 : \beta_j = 0 \qquad\qquad t_j = \frac{\widehat{\beta}_j}{\widehat{\sigma}(\widehat{\beta}_j)} \;\sim\; \text{Student à } n-k-1 \text{ ddl}

Démonstration : Pourquoi t_j suit une loi de Student à n-k-1 degrés de liberté

On suppose les erreurs \varepsilon_i \sim \mathcal{N}(0,\sigma_\varepsilon^2) indépendantes. Soit u le résidu de la variable x_j sur toutes les autres colonnes de X. Comme dans la démonstration de Frisch-Waugh (chapitre 7), u est orthogonal à ces colonnes, donc \sum_i u_ix_{ji} = \sum_i u_i^2 et \sum_i u_iy_i = \beta_j\sum_i u_i^2 + \sum_i u_i\varepsilon_i ; or \widehat{\beta}_j = \sum_i u_iy_i/\sum_i u_i^2. Donc \widehat{\beta}_j = \beta_j + \sum_i u_i\varepsilon_i/\sum_i u_i^2.

1. \widehat{\beta}_j est normale. C’est une combinaison linéaire de variables normales, de moyenne \beta_j et de variance \sigma_\varepsilon^2/\sum_i u_i^2. Donc Z = (\widehat{\beta}_j-\beta_j)\big/\big(\sigma_\varepsilon/\sqrt{\sum_i u_i^2}\big) \sim \mathcal{N}(0,1).

2. Elle est indépendante des résidus. Avec les notations de la démonstration du chapitre 7 sur les degrés de liberté, e = M\varepsilon et \widehat{\beta}_j - \beta_j = u'\varepsilon/\sum_i u_i^2, donc \mathrm{cov}(\widehat{\beta}_j, e) = \frac{\sigma_\varepsilon^2}{\sum_i u_i^2}\,Mu = 0, puisque u est une combinaison des colonnes de X et que MX = 0. Conjointement normales et non corrélées, \widehat{\beta}_j et e sont indépendantes, donc \widehat{\beta}_j et \text{SCR} aussi.

3. La somme des carrés (résultat admis). On admet, théorème de Fisher et Cochran, que \text{SCR}/\sigma_\varepsilon^2 \sim \chi^2(n-k-1) : les n résidus obéissent aux k+1 contraintes X'e = 0.

4. Conclusion. En remplaçant \sigma_\varepsilon par \widehat{\sigma}_\varepsilon = \sqrt{\text{SCR}/(n-k-1)}, t_j = \frac{Z}{\sqrt{\dfrac{\text{SCR}/\sigma_\varepsilon^2}{n-k-1}}}, quotient d’une \mathcal{N}(0,1) par la racine d’un \chi^2 divisé par ses degrés de liberté, les deux étant indépendants : c’est une loi de Student à n-k-1 degrés de liberté.

∎

Les quatre derniers mots sont essentiels

Le t de l’ancienneté ne dit pas si l’ancienneté compte : il dit si elle apporte quelque chose que le diplôme et la région n’apportent pas déjà.

Une variable peut être décisive seule et non significative en présence d’une autre qui la double. Ce n’est pas une contradiction, c’est le sens du ceteris paribus.

Le revenu des cinq ménages, seul puis accompagné

Le même coefficient, deux questions
Modèle \widehat{\beta}_R erreur-type t
C sur R 0{,}75 0{,}25 3{,}00
C sur R et T 0{,}50 0{,}354 1{,}41
Pourquoi le t baisse

Le coefficient baisse — une partie de l’effet brut revenait à la taille — et son erreur-type monte, de 0{,}25 à 0{,}354 : revenu et taille sont liés, la part « libre » du revenu est plus petite. C’est le prix du ceteris paribus, et le chapitre 13 le chiffrera.

Le cas d’école qui déroute

Un F très significatif, aucun t significatif

Cela se produit, et ce n’est pas une erreur de calcul.

C’est la signature de la multicolinéarité : les variables comptent ensemble, mais aucune ne se distingue des autres. Le chapitre 13 en donnera une démonstration complète sur nos données.

La règle de lecture

Un F significatif dit qu’il y a de l’information dans le bloc. Les t disent d’où elle vient.

Quand le premier parle et que les seconds se taisent, l’information est là mais on ne sait pas à qui l’attribuer.

Le test de restrictions

Tester plusieurs coefficients ensemble

Le Fisher partiel

F = \frac{(\text{SCR}_{\text{contraint}} - \text{SCR}_{\text{libre}})/q}{\text{SCR}_{\text{libre}}/(n-k-1)}

où q est le nombre de restrictions testées, et k le nombre de variables du modèle libre.

La logique, en une phrase

On estime le modèle avec et sans les variables en question, et l’on regarde de combien la somme des carrés résiduels augmente quand on les retire.

Si elle augmente peu, elles n’apportaient rien.

Sur les cinq ménages : retirer la taille

Une seule restriction

Modèle contraint : C sur R, \text{SCR} = 7{,}5. Modèle libre : C sur R et T, \text{SCR} = 5. F = \frac{(7{,}5 - 5)/1}{5/2} = 1 = t_T^2

Pour une seule restriction, F est le carré de t

Le Fisher partiel à q = 1 et le test de Student du coefficient sont le même test. Le Fisher n’apporte du nouveau qu’à partir de deux restrictions.

Démonstration : Le Fisher partiel : cas q = 1, et le test global comme cas particulier

Une restriction : F = t^2. Soit x_j la variable dont on teste le coefficient dans le modèle libre, et u son résidu sur les autres colonnes. D’après la démonstration du R^2 ajusté (chapitre 8), \text{SCR}_{\text{contraint}} - \text{SCR}_{\text{libre}} = \widehat{\beta}_j^{\,2}\sum_i u_i^2 et \widehat{\sigma}(\widehat{\beta}_j)^2 = \widehat{\sigma}_{\text{libre}}^2/\sum_i u_i^2. Donc F = \frac{\text{SCR}_{\text{contraint}} - \text{SCR}_{\text{libre}}}{\text{SCR}_{\text{libre}}/(n-k-1)} = \frac{\widehat{\beta}_j^{\,2}\sum_i u_i^2}{\widehat{\sigma}_{\text{libre}}^2} = t_j^2. Or t_j = Z/\sqrt{\chi^2_{\nu}/\nu} avec \nu = n-k-1, donc t_j^2 = \chi^2_1\big/(\chi^2_{\nu}/\nu) : une loi de Fisher à 1 et \nu degrés de liberté.

Le test global. Sous H_0 : \beta_1 = \dots = \beta_k = 0, le modèle contraint est y = \beta_0 + \varepsilon, dont la solution est \widehat{\beta}_0 = \overline{y} et la somme des carrés résiduels \text{SCT}. Le numérateur (\text{SCR}_{\text{contraint}} - \text{SCR}_{\text{libre}})/q avec q = k vaut (\text{SCT} - \text{SCR})/k = \text{SCE}/k : le F global est un Fisher partiel à q = k restrictions.

Plusieurs restrictions (résultat admis). Pour q \geq 2, on admet que, sous H_0, (\text{SCR}_{\text{contraint}} - \text{SCR}_{\text{libre}})/\sigma_\varepsilon^2 \sim \chi^2(q), indépendante de \text{SCR}_{\text{libre}}/\sigma_\varepsilon^2 \sim \chi^2(n-k-1) ; leur quotient, divisé par les degrés de liberté, est une loi de Fisher à q et n-k-1 degrés de liberté.

∎

Quand il est indispensable

Les groupes d’indicatrices

Le diplôme est représenté par deux indicatrices. Tester leurs deux t séparément gonflerait le risque, exactement comme les comparaisons deux à deux du chapitre 17 de l’inférence.

La question correcte est : le diplôme, dans son ensemble, apporte-t-il quelque chose ? Elle exige un Fisher partiel à q=2 restrictions.

Le diplôme, testé correctement

Modèle libre M2 contre modèle contraint M1 :

Sommes des carrés résiduels, en millions : 2\,009 contre 1\,209.

F = \frac{(2\,009 - 1\,209)/2}{1\,209/496} = 164{,}0 \qquad \text{contre un seuil de } 3{,}01

Le diplôme compte, et le test le dit d’un seul coup — sans multiplier les risques.

La région, d’un bloc

Trois indicatrices, trois restrictions

M3 (sans région) contre M4 (avec) : \text{SCR} = 1\,206{,}9 et 1\,119{,}2 millions. F = \frac{(1\,206{,}9 - 1\,119{,}2)/3}{1\,119{,}2/492} = \frac{29{,}25}{2{,}275} = 12{,}86 \qquad \text{seuil } F_{3\,;492} = 2{,}62

Tester une hypothèse économique

Le test de restrictions n’est pas réservé aux blocs

Il permet de tester toute contrainte linéaire sur les coefficients : \beta_1 = \beta_2, \beta_1 + \beta_2 = 1, \beta_3 = 0{,}5.

Un exemple classique

Dans une fonction de production \ln Q = \beta_0 + \beta_1 \ln K + \beta_2 \ln L + \varepsilon, l’hypothèse de rendements d’échelle constants s’écrit \beta_1 + \beta_2 = 1.

C’est une hypothèse économique, testable par un simple Fisher partiel. C’est ici que la boucle du chapitre 1 se referme : la théorie impose une contrainte, les données l’acceptent ou la refusent.

Casablanca et Rabat : une même prime ?

Une contrainte d’égalité

Dans M4, Casablanca vaut 1\,177{,}84 et Rabat 978{,}52, par rapport aux « Autres » régions. Le modèle contraint par \beta_{\text{Casa}} = \beta_{\text{Rabat}} a une SCR de 1\,121{,}5 millions : F = \frac{(1\,121{,}5 - 1\,119{,}2)/1}{1\,119{,}2/492} = 1{,}02 \qquad p = 0{,}31

Deux coefficients différents, une même prime

Deux cents dirhams d’écart entre les deux estimations, et pourtant aucune différence significative : les deux grandes villes paient, à caractéristiques égales, une prime qu’on ne sait pas distinguer. On pourrait les réunir en une seule indicatrice.

Les trois tests avec Python

import pandas as pd
import statsmodels.formula.api as smf
sal = pd.read_csv("salaires.csv")
f3 = "salaire ~ anciennete + diplome + sexe"
m3 = smf.ols(f3, data=sal).fit()
m4 = smf.ols(f3 + " + region", data=sal).fit()
print(round(m4.fvalue, 2), m4.df_model, m4.df_resid)   # F global
# 141.67 7.0 492.0
F, p, q = m4.compare_f_test(m3)    # Fisher partiel, la région
print(round(F, 3), f"{p:.1e}", q)
# 12.856 4.2e-08 3.0
ft = m4.f_test("region[T.Casablanca] = region[T.Rabat]")
print(round(float(ft.fvalue), 4), round(float(ft.pvalue), 4))
# 1.0184 0.3134

Ce que disent les sorties

Trois commandes, trois questions

fvalue : le test global. compare_f_test en Python, anova(m3, m4) en R : le Fisher partiel entre deux modèles emboîtés — les deux SCR, q = 3 et F = 12{,}86. f_test et linearHypothesis : n’importe quelle contrainte linéaire, écrite en clair.

Emboîtés, et sur les mêmes observations

Le Fisher partiel ne compare que des modèles emboîtés — l’un est l’autre avec des coefficients contraints — et estimés sur les mêmes lignes. Comparer M4 à un modèle en logarithme, ou à un modèle estimé sans quelques salariés, n’aurait aucun sens.

S’entraîner

Exercice 1 : un Fisher partiel à la main

Deux variables de trop

Sur n = 100 entreprises, un modèle libre à k = 5 variables a une SCR de 480. Sans deux de ses variables, la SCR passe à 520.

  1. Écrire l’hypothèse testée.
  2. Calculer la statistique F.
  3. Conclure à 5\,\%, sachant que F_{2\,;94} = 3{,}09.

Exercice 1 : solution

Les deux variables comptent
  1. H_0 : les deux coefficients retirés sont tous deux nuls.
  2. F = \dfrac{(520 - 480)/2}{480/94} = \dfrac{20}{5{,}106} = 3{,}92.
  3. 3{,}92 > 3{,}09 : on rejette H_0. Au moins une des deux variables apporte une information que les trois autres n’apportent pas.

Exercice 2 : le F global à partir du R²

Un modèle qui ne dit presque rien

Sur n = 50 observations, un modèle à k = 4 variables donne R^2 = 0{,}25. Aucun des quatre t ne dépasse 1{,}6.

  1. Calculer le F global (F_{4\,;45} = 2{,}58) et conclure.
  2. Comment concilier ce résultat avec les quatre t ?

Exercice 2 : solution

Le bloc parle, les variables se taisent
  1. F = \dfrac{0{,}25/4}{0{,}75/45} = \dfrac{0{,}0625}{0{,}0167} = 3{,}75 > 2{,}58 : on rejette l’hypothèse que les quatre variables sont toutes sans effet.
  2. Les variables sont probablement liées entre elles : ensemble elles expliquent quelque chose, séparément aucune ne se distingue. C’est la signature de la multicolinéarité, chapitre 13.

Exercice 3 : quel test pour quelle question

Quatre questions sur M4

Pour chaque question, indiquer le test et le nombre de restrictions q.

  1. Le modèle explique-t-il quelque chose du salaire ?
  2. Le sexe compte-t-il, à caractéristiques égales ?
  3. La région compte-t-elle ?
  4. Le Bac+5 rapporte-t-il exactement trois fois le Bac+2 ?

Exercice 3 : solution

Un test par question
  1. Le F global, q = 7 : F = 141{,}7, rejet.
  2. Le t du sexe, ou un Fisher partiel à q = 1 — c’est le même test : t = 1{,}27, non significatif.
  3. Le Fisher partiel à q = 3 : F = 12{,}86, rejet.
  4. Une contrainte linéaire, \beta_{5} = 3\,\beta_{2}, testée par un Fisher à q = 1 — linearHypothesis en R, f_test en Python.

Ce qu’il faut retenir

Le résumé du chapitre

Six points
  1. F global : toutes les variables sont-elles sans effet ? Presque toujours rejeté, donc peu informatif.
  2. t individuels : cette variable apporte-t-elle quelque chose que les autres n’apportent pas ?
  3. Fisher partiel : plusieurs coefficients ensemble ; à q = 1, c’est t^2 — 1 pour la taille des cinq ménages.
  4. Il est obligatoire pour un groupe d’indicatrices : diplôme 164{,}0, région 12{,}86.
  5. Il teste aussi les contraintes économiques : rendements constants, égalité de deux primes.
  6. Un F significatif avec aucun t significatif signale la multicolinéarité.
