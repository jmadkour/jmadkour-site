Une seule ligne compte

La carte

La ligne de partage

Deux familles de problèmes

Ceux qui faussent les écarts-types : hétéroscédasticité, erreurs groupées, multicolinéarité, et la non-normalité à petit échantillon. Les coefficients restent justes.

Celui qui fausse les coefficients : la variable omise. Rien d’autre ne compte autant.

La conséquence sur la façon de travailler

Les premiers se détectent par un test et se réparent par une formule. Ce sont des problèmes techniques, et ils ont des solutions techniques.

Le second se détecte par le raisonnement économique — car la variable manquante n’est pas dans les données — et se répare en changeant de modèle. C’est un problème de spécification, et aucun logiciel ne le résoudra.

Chaque problème sur le terrain où il se rencontre

Le regroupement n’existe que dans l’enquête de ménages, tirée par quartiers ; l’hétéroscédasticité est spectaculaire sur les salaires. On ne fabrique pas les problèmes : on les cherche là où ils sont.

Le rôle des résidus

Le seul matériau du diagnostic

Ce qu’on regarde

Les erreurs \varepsilon_i sont inconnues. Les résidus e_i sont calculés.

Tout diagnostic passe par les résidus : ils sont la seule trace observable de ce que le modèle n’explique pas.

Un principe qui ne varie pas

Sous les hypothèses, les résidus doivent ressembler à du bruit pur : aucune structure, aucune tendance, aucune relation avec quoi que ce soit.

Toute régularité visible dans les résidus est une information que le modèle a laissée échapper. C’est le fil conducteur des cinq chapitres qui suivent.

Ils coûtent quatre lignes de code

Aucun de ces quatre graphiques ne prend plus de dix secondes à produire, et l’un d’eux vaut souvent mieux qu’une batterie de tests.

Un test dit si un problème existe ; un graphique dit à quoi il ressemble. Les deux sont nécessaires, et le graphique vient d’abord.

Comment les tests fonctionnent

Un principe commun

La régression auxiliaire

La plupart des tests de diagnostic suivent le même schéma :

  1. estimer le modèle et récupérer les résidus ;
  2. régresser une fonction des résidus sur quelque chose ;
  3. si cette seconde régression explique quelque chose, l’hypothèse est violée.
Trois tests, un seul principe
Test On régresse Sur
Breusch-Pagan e_i^2 les variables explicatives
White e_i^2 variables, carrés, produits
RESET y_i variables et puissances de \widehat{y}_i

La statistique et sa loi

Toujours la même

n R^2_{\text{auxiliaire}} \;\sim\; \chi^2_{q}

où q est le nombre de variables ajoutées dans la régression auxiliaire.

Pourquoi un khi-deux

Parce qu’on additionne des écarts au carré — c’est le signe reconnu au chapitre 18 de l’inférence.

Et le test est unilatéral à droite : seule une valeur élevée contredit l’hypothèse d’absence de problème. Là encore, rien de nouveau : on applique un test appris ailleurs.

Breusch-Pagan à la main, sur les cinq ménages

Les carrés des résidus contre le revenu
Ménage A B C D E
R - \overline{R} -4 -2 0 2 4
e^2 0 2{,}25 4 0{,}25 1

Moyenne de e^2 : 7{,}5/5 = 1{,}5. Pente de e^2 sur R : \sum (R-\overline{R})(e^2 - 1{,}5)/40 = (6 - 1{,}5 + 0 - 2{,}5 - 2)/40 = 0.

Un R^2 auxiliaire nul

La régression auxiliaire n’explique rien : nR^2 = 0. Breusch-Pagan ne voit aucune hétéroscédasticité liée au revenu. Il ne cherche que des liaisons linéaires entre e^2 et les variables — et cinq points ne permettraient pas d’en voir d’autres.

Sur les salaires

Deux régressions auxiliaires

Breusch-Pagan : e^2 régressé sur l’ancienneté et les deux indicatrices de diplôme donne R^2_{\text{aux}} = 0{,}1152, d’où nR^2 = 500 \times 0{,}1152 = 57{,}6, contre un seuil de 7{,}81 pour \chi^2_3.

RESET : ajouter \widehat{y}^2 au modèle M2 donne F = 5{,}77, p = 0{,}017.

Deux signaux, deux chapitres

Le premier dit que la dispersion des erreurs dépend des variables : c’est le chapitre 14. Le second qu’une courbure a été oubliée : la forme logarithmique du chapitre 18 y répondra. Les deux signaux ont la même origine, comme on le verra : un salaire est une grandeur multiplicative.

Une mise en garde sur les tests de diagnostic

Ils sont sensibles à la taille de l’échantillon

Sur cinq cents observations, la moindre hétéroscédasticité devient significative. Sur trente, une hétéroscédasticité massive peut passer inaperçue.

Un test qui rejette ne dit pas que le problème est grave. Il dit qu’il existe. Le graphique dit s’il compte.

La bonne pratique

Sur données individuelles, l’usage actuel est de ne même plus tester l’hétéroscédasticité : on la suppose présente et l’on publie directement des écarts-types robustes.

Le test garde son intérêt pédagogique — il fait comprendre le mécanisme — et son intérêt pratique quand le remède coûte quelque chose.

Sur machine

Breusch-Pagan avec R

suppressPackageStartupMessages(library(lmtest))
sal <- read.csv("salaires.csv", stringsAsFactors = TRUE)
m2 <- lm(salaire ~ anciennete + diplome, data = sal)
aux <- lm(residuals(m2)^2 ~ anciennete + diplome, data = sal)
500 * summary(aux)$r.squared         # n R2 auxiliaire, à la main
# [1] 57.59655
bptest(m2)                           # la même chose
#
#  studentized Breusch-Pagan test
#
# data:  m2
# BP = 57.597, df = 3, p-value = 1.917e-12

Breusch-Pagan et RESET avec Python

import pandas as pd
import statsmodels.formula.api as smf
import statsmodels.stats.diagnostic as dg
sal = pd.read_csv("salaires.csv")
m2 = smf.ols("salaire ~ anciennete + diplome", data=sal).fit()
bp, p_bp, _, _ = dg.het_breuschpagan(m2.resid, m2.model.exog)
print(round(bp, 2), f"{p_bp:.1e}")
# 57.6 1.9e-12
r = dg.linear_reset(m2, power=2, use_f=True)
print(round(r.fvalue, 2), round(r.pvalue, 4))
# 5.77 0.0167

S’entraîner

Exercice 1 : Breusch-Pagan à la main

Les quatre magasins

Les résidus de \widehat{y} = 0{,}5 + 1{,}5\,x sont 0 ; 0{,}5 ; -1{,}5 ; 1, pour x = 1, 2, 4, 5.

  1. Calculer les e^2 et leur moyenne.
  2. Calculer la pente et le R^2 de la régression de e^2 sur x.
  3. En déduire la statistique de Breusch-Pagan et conclure (\chi^2_1 = 3{,}84).

Exercice 1 : solution

Une liaison visible, non significative
  1. e^2 = 0 ; 0{,}25 ; 2{,}25 ; 1, de moyenne 0{,}875.
  2. Écarts de x : -2, -1, 1, 2 (S_{xx} = 10). \sum (x-\overline{x})(e^2 - 0{,}875) = 1{,}75 + 0{,}625 + 1{,}375 + 0{,}25 = 4 : pente 0{,}4. SCE = 0{,}4^2 \times 10 = 1{,}6 ; SCT = 3{,}0625 ; R^2 = 0{,}522.
  3. nR^2 = 4 \times 0{,}522 = 2{,}09 < 3{,}84 : on ne rejette pas. La dispersion semble croître avec x, mais quatre points ne suffisent pas à le prouver.

Exercice 2 : lire un graphique de résidus

Quatre formes

Quel problème suggère chacune des formes suivantes du graphique des résidus contre les valeurs ajustées ?

  1. Un éventail qui s’ouvre vers la droite.
  2. Une courbe en U.
  3. Des paquets de points au-dessus, d’autres au-dessous de zéro, selon le quartier.
  4. Un nuage sans forme, avec trois points très au-dessus des autres.

Exercice 2 : solution

Quatre formes, quatre chapitres
  1. Hétéroscédasticité : la dispersion grandit avec le niveau — chapitre 14.
  2. Forme fonctionnelle : une courbure oubliée, qu’un carré ou un logarithme corrigerait — chapitre 18.
  3. Erreurs groupées : les ménages d’un quartier partagent une erreur commune — chapitre 15.
  4. Points atypiques : à examiner un par un, avec leur levier — chapitre 17.

Exercice 3 : la taille de l’échantillon

Le même R^2 auxiliaire

Deux études obtiennent le même R^2_{\text{aux}} = 0{,}02 dans une régression de Breusch-Pagan à une variable.

  1. Calculer la statistique pour n = 50 et pour n = 5\,000.
  2. Conclure dans chaque cas.
  3. Le problème est-il plus grave dans la seconde étude ?

Exercice 3 : solution

Significatif ne veut pas dire grave
  1. nR^2 = 1 pour n = 50 ; 100 pour n = 5\,000.
  2. Non-rejet dans le premier cas (1 < 3{,}84), rejet massif dans le second.
  3. Non : la régression auxiliaire explique la même part, 2\,\%, de la variance des e^2. Le second test rejette parce qu’il a plus d’observations, pas parce que le problème est plus grand. Le graphique, pas le test, dit si cela compte.

Ce qu’il faut retenir

Le résumé du chapitre

Six points
  1. Quatre violations ne touchent que les écarts-types ; une seule, la variable omise, biaise les coefficients.
  2. Les premières se détectent par un test et se réparent par une formule ; la seconde par le raisonnement.
  3. Tout diagnostic passe par les résidus : ils doivent ressembler à du bruit pur.
  4. Quatre graphiques, systématiquement : plot(m2) annonce déjà les chapitres 14 et 17.
  5. Les tests suivent tous le même schéma : une régression auxiliaire et un nR^2 lu dans un khi-deux.
  6. Salaires : Breusch-Pagan 57{,}6, RESET 5{,}77 ; cinq ménages : nR^2 = 0.
