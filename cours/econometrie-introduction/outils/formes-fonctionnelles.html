Modèle avec terme quadratique : ln(salaire) = β₀ + β₁·Exp + β₂·Exp² + ...

Deux R² ne se comparent jamais si la variable expliquée diffère (y contre ln y). L'approximation 100β sous-estime toujours l'effet réel au-delà de β ≈ 0,1 ; utiliser alors 100(e^β − 1).
