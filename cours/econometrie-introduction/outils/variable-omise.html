Chapitre 16 — La variable omise

Calculatrice interactive — biais de variable omise et raisonnement sur son signe

Calculer le biais γ·δ

Vrai modèle : y = β₀ + β₁x + γz + ε. Biais espéré sur le coefficient de x si z est omise : γ × δ, où δ est la pente de la régression de z sur x.

Vérifier l'identité sur plusieurs variables omises

Une variable par ligne, format nom,gamma,delta. Exemple : diplôme du modèle salaire du cours.

Raisonner sur le signe, sans données

Le biais de variable omise ne se détecte par aucun test et ne se corrige par aucune formule appliquée aux données disponibles : il faut soit ajouter la variable, soit la substituer, soit raisonner sur son signe probable.
