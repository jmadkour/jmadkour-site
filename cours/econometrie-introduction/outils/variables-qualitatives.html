Chapitre 10 — Les variables qualitatives

Calculatrice interactive — indicatrices, changement de référence et interaction

Changer de référence, sans changer les prédictions

Une modalité par ligne, format nom,ecart_vs_reference. La première ligne (écart = 0) est la référence actuelle.

Modèle avec interaction

Changer la modalité de référence ne change jamais les prédictions du modèle — seulement la façon dont les coefficients doivent être lus.
