La corrélation de défaut et la probabilité de défaut conjoint

Probabilité de défaut conjoint sous corrélation : pi12 = rho12 x racine(pi1 x (1-pi1) x pi2 x (1-pi2)) + pi1 x pi2. Modèle à un facteur : rho12 = beta au carré ; probabilité de défaut conditionnelle p(m) = Phi((k - beta x m) / racine(1 - beta au carré)), avec k = Phi inverse(pi).

La VaR de crédit d'un portefeuille granulaire homogène (modèle de Vasicek)

Perte attendue EL = V x pi x LGD. Taux de défaut le pire cas WCDR(1 an, X) = Phi((Phi inverse(pi) + racine(rho) x Phi inverse(X)) / racine(1 - rho)). Quantile de perte = WCDR x V x LGD. VaR de crédit = quantile de perte moins EL.
