Shortfall de capital sous scénario adverse : bilan statique, bilan dynamique, incertitude sur les revenus

CET1 stresse = CET1 initial - Pertes L + PPNR R. Shortfall = max(0, (hurdle rate - ratio stresse) x RWA stresse). Bilan dynamique : le RWA croit du taux indique sur l'horizon du test, L et R inchanges. Incertitude sur les revenus : seul le PPNR realise (en % du PPNR projete) est retenu, L inchange.

Divulgation granulaire ou agrégée : quantifier le coût de financement et la subvention croisée

Besoin de capital d'une banque = shortfall (% du RWA) x RWA. Sous divulgation granulaire, chaque banque paie un spread proportionnel a son propre shortfall : spread_i = coefficient x shortfall_i(%). Sous divulgation agregee, toutes les banques paient le meme spread, calcule a partir du seul shortfall global du systeme. Surcout annuel (M€) = spread (pb) / 10000 x financement (Md€) x 1000.
