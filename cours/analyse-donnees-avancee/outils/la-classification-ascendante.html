2. Décomposition de l'inertie d'une partition

Une classe par ligne : effectif, puis coordonnées du barycentre $F_1$, $F_2$ (séparés par des espaces). Le barycentre global est calculé comme la moyenne pondérée.

Rappels : $\Delta(a,b)=\dfrac{n_an_b}{n_a+n_b}d^2(G_a,G_b)$ ; l'inertie interclasse d'une partition est $I_{\text{inter}}=\sum_k f_k\,d^2(G_k,\mathbf{g})$, où $\mathbf{g}$ est le barycentre global ; $I_{\text{totale}}=I_{\text{intra}}+I_{\text{inter}}$. Un pourcentage d'inertie interclasse élevé n'est pas comparable entre partitions ayant des nombres de classes différents.
