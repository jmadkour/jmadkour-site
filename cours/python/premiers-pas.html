Premiers pas en Python

Outils — Python, chapitre 1

Ici, rien à installer. Chaque encadré ci-dessous est une console : modifiez le code, cliquez sur Exécuter, lisez le résultat. Le premier lancement demande une dizaine de secondes, le temps que Python arrive dans votre navigateur.

On ne va pas apprendre « la programmation ». On va répondre à des questions d’économiste, et le code sera simplement l’outil qui donne la réponse.

Le prix du café a-t-il vraiment augmenté ?

Un café coûtait 8 dirhams en 2015, il en coûte 12 aujourd’hui. De combien a-t-il augmenté, en pourcentage ?

prix_2015 = 8 prix_2026 = 12 hausse = (prix_2026 - prix_2015) / prix_2015 * 100 print(hausse)

Cinquante pour cent. Trois remarques sur ce que vous venez de faire :

  • prix_2015 = 8 range la valeur 8 dans une boîte nommée prix_2015. Le signe = ne dit pas « est égal à », il dit « mets dedans ».
  • Python respecte les priorités : la division s’effectue avant la multiplication par 100 seulement parce que les parenthèses l’imposent au numérateur.
  • print affiche. Sans lui, le calcul se ferait dans le vide.
Astuce

Essayez : remplacez 12 par 10, exécutez. Puis mettez le prix de votre propre café.

Mais 50 %, est-ce beaucoup ?

Tout dépend de l’inflation générale. Si tous les prix ont augmenté de 30 % sur la période, le café n’a réellement renchéri que de la différence.

prix_2015 = 8 prix_2026 = 12 inflation = 30 # hausse generale des prix, en % # ce que couterait le cafe s'il avait simplement suivi l'inflation attendu = prix_2015 * (1 + inflation / 100) print("Prix attendu :", attendu) # l'ecart reel print("Ecart :", prix_2026 - attendu, "dirhams")

Le café a bien augmenté plus vite que la moyenne : c’est un renchérissement réel de 1,60 dirham, pas de 4.

NoteLa distinction qui structure tout le reste

Nominal, c’est ce qui est écrit sur l’étiquette. Réel, c’est ce que ça représente une fois l’inflation retirée. Un salaire qui augmente de 3 % quand les prix montent de 5 % baisse. Vous retrouverez cette distinction dans tous vos cours de macroéconomie.

Notez au passage le # : tout ce qui le suit est un commentaire, ignoré par Python. Il est là pour vous, pas pour la machine.

Plusieurs prix à la fois

Un seul produit n’apprend pas grand-chose. Voici un petit panier.

produits = ["Pain", "Lait", "Cafe", "Essence", "Loyer"] prix_2015 = [1.2, 6.5, 8.0, 9.4, 2500] prix_2026 = [1.5, 8.0, 12.0, 13.2, 3400] for i in range(5): hausse = (prix_2026[i] - prix_2015[i]) / prix_2015[i] * 100 print(produits[i], ":", round(hausse, 1), "%")

Une liste rassemble plusieurs valeurs sous un seul nom, entre crochets. La boucle for répète le calcul pour chaque position. Et round(x, 1) arrondit à une décimale — sans quoi Python afficherait quinze chiffres après la virgule.

AvertissementOn compte à partir de zéro

produits[0] est Pain, produits[1] est Lait. Le premier élément porte le numéro 0. C’est déroutant les premiers jours, puis on n’y pense plus. produits[5] n’existe pas et provoque une erreur : essayez, pour voir à quoi ressemble un message d’erreur.

Le panier moyen

Faire la moyenne des hausses serait une erreur : le loyer pèse bien plus lourd que le pain dans un budget. Il faut pondérer.

prix_2015 = [1.2, 6.5, 8.0, 9.4, 2500] prix_2026 = [1.5, 8.0, 12.0, 13.2, 3400] # part de chaque poste dans le budget d'un menage poids = [0.10, 0.10, 0.05, 0.15, 0.60] depense_2015 = 0 depense_2026 = 0 for i in range(5): depense_2015 = depense_2015 + prix_2015[i] * poids[i] depense_2026 = depense_2026 + prix_2026[i] * poids[i] indice = depense_2026 / depense_2015 * 100 print("Indice des prix :", round(indice, 1)) print("Inflation cumulee :", round(indice - 100, 1), "%")

Vous venez de calculer un indice des prix, exactement selon le principe qu’appliquent le HCP au Maroc et l’INSEE en France. Le loyer, qui pèse 60 % du budget, dicte presque entièrement le résultat.

Astuce

Essayez : donnez au loyer un poids de 0.30 et redistribuez le reste. L’inflation calculée change nettement — ce qui explique pourquoi le choix des pondérations est un sujet politique autant que technique.

Nommer un calcul pour le réutiliser

Recopier le même calcul dix fois est le meilleur moyen de s’y tromper. Une fonction lui donne un nom une fois pour toutes.

def taux_de_croissance(depart, arrivee): return (arrivee - depart) / depart * 100 # le PIB marocain, en milliards de dirhams print("2023 -> 2024 :", round(taux_de_croissance(1450, 1520), 2), "%") print("2024 -> 2025 :", round(taux_de_croissance(1520, 1585), 2), "%")

def ouvre la définition, return indique ce que la fonction renvoie. Les quatre espaces en début de ligne — l’indentation — délimitent le corps de la fonction. Ce n’est pas décoratif : supprimez-les et Python refuse de continuer.

Et si on demandait à Python de décider ?

croissance = 1.8 inflation = 4.2 if croissance > inflation: print("Le pouvoir d'achat progresse.") elif croissance == inflation: print("Le pouvoir d'achat stagne.") else: print("Le pouvoir d'achat recule.")

Attention au double signe égal. = affecte une valeur, == compare. Les confondre est l’erreur la plus fréquente des premières semaines.

À vous

Un salaire de 5 000 dirhams augmente de 3 % par an. Les prix, eux, montent de 5 % par an. Que devient le pouvoir d’achat au bout de cinq ans ?

Le squelette est là, complétez les deux lignes marquées.

salaire = 5000 prix = 100 # niveau general des prix, base 100 for annee in range(1, 6): salaire = salaire * 1.03 prix = ... # a completer : les prix montent de 5 % pouvoir = ... # a completer : salaire rapporte au niveau des prix print("Annee", annee, ":", round(pouvoir, 1))
NoteLa solution 
prix = prix * 1.05
pouvoir = salaire / prix * 100

Le pouvoir d’achat part de 5 000, tombe à 4 905 dès la première année et finit à 4 542 : il recule de 9,2 % en cinq ans, alors que le salaire, lui, a bel et bien augmenté chaque année. C’est toute la différence entre nominal et réel — et une source classique d’incompréhension dans le débat public.
