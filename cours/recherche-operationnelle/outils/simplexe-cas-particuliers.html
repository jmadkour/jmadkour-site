Dérouler le simplexe et diagnostiquer les cas particuliers

$\max Z=c_1x+c_2y$ sous $a_1x+b_1y\leq d_1$, $a_2x+b_2y\leq d_2$, $x,y\geq0$. L'outil signale un optimum multiple (coût réduit nul hors base), une dégénérescence (variable de base nulle) ou une solution non bornée (colonne entièrement négative).

Rappels : un coût réduit nul sur une variable hors base à l'optimum signale un optimum multiple (une face entière du polyèdre est optimale) ; une variable de base à zéro signale une dégénérescence ; une variable de coût réduit positif dont toute la colonne est $\leq0$ signale une solution non bornée --- presque toujours une contrainte oubliée.
