Chapitre 2 — Le programme linéaire et ses formes

Calculatrice interactive — Recherche opérationnelle

1. Convertir un système de contraintes en forme standard

Une ligne par contrainte, au format "coefficients séparés par des virgules ; sens ; valeur", où sens = le (≤), ge (≥) ou eq (=). Exemple pour deux variables : "2,1;le;100". Le nombre de coefficients fixe le nombre de variables de décision.

2. Compter les choix de base possibles

Nombre de variables de décision, puis nombre de contraintes (une variable d'écart est ajoutée par contrainte). Le calcul se déduit automatiquement du panneau 1 si vous avez cliqué sur "Convertir", mais vous pouvez aussi saisir directement.

Rappels : une contrainte $\leq$ reçoit $+e_i$, une contrainte $\geq$ reçoit $-e_i$ (variable de surplus), une contrainte $=$ n'a besoin d'aucune variable ; $\min$ se réécrit $\max(-\cdot)$ ; le nombre de choix de base $\binom{n}{m}$ compte toutes les solutions de base algébriques, mais seules celles à composantes positives ou nulles sont réalisables.
