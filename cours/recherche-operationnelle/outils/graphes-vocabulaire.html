Chapitre 10 — Les graphes : vocabulaire et représentation

Calculatrice interactive — Recherche opérationnelle

Décrire le graphe

Une ligne par arc/liaison : Origine,Destination ou, pour une valeur (poids), Origine,Destination,valeur. Les sommets isolés doivent aussi apparaître : ajouter une ligne Sommet, (destination vide) si besoin.

Rappels du cours : demi-degré entrant $d^-$ = nombre d'arcs qui arrivent ; demi-degré sortant $d^+$ = nombre d'arcs qui partent ; source = $d^-=0$ ; puits = $d^+=0$ ; $(A^k)_{ij}$ compte les chemins de longueur exactement $k$ de $i$ à $j$ ; un graphe (orienté) est fortement connexe si $A+A^2+\dots+A^{n-1}$ n'a aucun zéro hors de la diagonale ; la matrice des valeurs remplace les zéros d'absence d'arc par $+\infty$.
