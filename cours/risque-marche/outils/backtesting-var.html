Le test binomial de défaillance

$z=(N-pT)/\sqrt{p(1-p)T}$. Le modèle est rejeté au niveau de test de 95~\% si $|z|>1{,}96$.

Les zones de Bâle : erreurs de type 1 et de type 2

Erreur de type 1 : $P(N\geq\text{seuil}\mid T,p)$, modèle correct rejeté à tort. Erreur de type 2 : $P(N<\text{seuil}\mid T,p_{\text{vrai}})$, modèle incorrect non rejeté.
