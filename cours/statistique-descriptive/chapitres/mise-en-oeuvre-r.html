Le but n’est pas d’apprendre R

C’est de vérifier que les résultats calculés à la main sont bien ceux que produit un logiciel — et de constater qu’une quinzaine de lignes de code remplacent un semestre de calculs.

Avant de commencer

Ce qu’il faut installer, une seule fois
  1. R, le langage, et RStudio, l’éditeur : tous deux gratuits.
  2. Le fichier salaires.csv dans le dossier de travail de RStudio.
  3. Un seul package supplémentaire, pour l’asymétrie et l’aplatissement : install.packages("moments").
Comprendre la formule reste indispensable

C’est ce qui permet de savoir quelle fonction demander, avec quels arguments — et de reconnaître un résultat aberrant. Les cinq pièges de ce chapitre sont tous des pièges de convention, invisibles pour qui ne connaît pas la formule.

Le premier réflexe : vérifier les types

Factor pour les qualitatives, int ou num pour les quantitatives

Si R a lu salaire comme un facteur, c’est qu’une ligne contient du texte — un espace, une virgule décimale, un « n.d. ». Toutes les moyennes seraient alors impossibles. C’est la première erreur à chercher dans un fichier réel.

Variable continue : le découpage en classes

bornes <- c(2000, 4000, 6000, 8000, 10000, 14000, 20000)
cl <- cut(sal$salaire, breaks = bornes, right = FALSE,
          dig.lab = 5)                   # classes [a ; b[
ni <- as.numeric(table(cl))              # effectifs
ai <- diff(bornes)                       # amplitudes
di <- ni / ai                            # densités
print(data.frame(classe = levels(cl), ni, fi = ni/n, ai, di),
      digits = 3)
Les bornes, les amplitudes, les densités

bornes fixe les sept bornes des six classes ; diff() en déduit les amplitudes, et la densité divise chaque effectif par son amplitude — la règle du chapitre 3, quand les classes sont inégales.

Le piège des bornes

L’argument right = FALSE est essentiel

Par défaut, R crée des classes ]a\,;\,b] — ouvertes à gauche, fermées à droite. C’est l’inverse de la convention française. right = FALSE rétablit [a\,;\,b[ ; dig.lab = 5 évite les bornes en notation scientifique, [2e+03,4e+03).

Sur nos données, un salarié change de classe

Un salarié gagne exactement 6\,000 dirhams. Avec [a\,;\,b[, il est dans la troisième classe ; sans right = FALSE, il passe dans la deuxième.

Classe [4\,000\,;6\,000[ [6\,000\,;8\,000[
Avec right = FALSE 157 166
Sans (défaut de R) 158 165

Ici l’écart est minime. Sur des salaires arrondis à la centaine, des dizaines d’individus tombent sur les bornes.

Sur données groupées : moyenne et écart-type

ci <- (head(bornes, -1) + bornes[-1]) / 2   # centres des classes
mg <- sum(ni * ci) / n                       # 7210     moyenne groupée
vg <- sum(ni * ci^2) / n - mg^2              # 7685900  König-Huygens
sqrt(vg)                                     # 2772.35  écart-type groupé
Les valeurs des chapitres 5 et 7, retrouvées
Groupé Exact Écart
Moyenne 7\,210 7\,158{,}26 +0{,}7\,\%
Écart-type 2\,772{,}35 2\,598{,}10 +6{,}7\,\%

Les centres de classe ignorent la répartition à l’intérieur des classes : l’écart-type groupé surestime la dispersion, surtout à cause des deux dernières classes, très larges.

Sur données groupées : mode et médiane

k  <- which.max(di)                          # classe modale : la 3e
d1 <- di[k] - di[k-1]; d2 <- di[k] - di[k+1]
bornes[k] + ai[k] * d1 / (d1 + d2)           # 6187.5   mode
Fk <- cumsum(ni) / n
j  <- which(Fk >= 0.5)[1]                    # classe médiane : la 3e
bornes[j] + ai[j] * (0.5 - Fk[j-1]) / (ni[j]/n)   # 6747   médiane
Le code est la formule

Chaque ligne traduit une formule du chapitre 5 : la classe de densité maximale, les deux écarts \Delta_1 et \Delta_2, puis l’interpolation linéaire dans la classe où F franchit 0{,}5. Écrire le code oblige à savoir exactement ce qu’on calcule.

Les quantiles de R sont ceux du chapitre 6

Par défaut, quantile() place x_p au rang 1 + p\,(n-1) et interpole : c’est la convention retenue au chapitre 6.

Le piège n contre n − 1

R divise par n − 1, pas par n

var() et sd() calculent la variance dite corrigée, celle de la statistique inférentielle. La variance descriptive du chapitre 7 divise par n : V_{\text{R}} = \frac{1}{n-1}\sum (x_i-\overline{x})^2 = \frac{n}{n-1}\,V \quad\Longrightarrow\quad V = \frac{n-1}{n}\,V_{\text{R}}

Sur nos 500 salariés
var(), sd() Descriptif Rapport
Variance 6\,763\,649 6\,750\,122 0{,}998
Écart-type 2\,600{,}70 2\,598{,}10 0{,}999

Négligeable sur 500 observations ; sur 10, le rapport tombe à 0{,}9 (exercice 1). Un écart avec un calcul manuel se vérifie d’abord ici.

La forme, sans package

m <- mean(x)
mean((x - m)^3) / mean((x - m)^2)^1.5     # 1.164   asymétrie
mean((x - m)^4) / mean((x - m)^2)^2       # 4.837   aplatissement

library(moments)                          # après install.packages
skewness(x); kurtosis(x)                  # les mêmes valeurs
La formule du chapitre 8, en une ligne

\gamma_1 = m_3/\sigma^3 et \gamma_2 = m_4/\sigma^4, avec des moments centrés divisés par n : mean() fait exactement cela. Le package ne fait rien de plus.

Vérifier la convention d’aplatissement

moments::kurtosis() donne \gamma_2, de référence 3. D’autres fonctions donnent l’excès \gamma_2 - 3, de référence 0 : on lirait 1{,}84. Les deux sont justes ; il faut savoir laquelle on regarde.

La concentration

gini <- function(v) {
  v <- sort(v); n <- length(v)
  2 * sum(seq_len(n) * v) / (n * sum(v)) - (n + 1) / n
}
gini(x)                          # 0.195
tapply(x, sal$diplome, gini)     # Bac 0.181   Bac+2 0.155   Bac+5 0.165
La formule des rangs, vérifiée sur deux cas extrêmes

Avec les x_{(i)} rangés par ordre croissant, G = \dfrac{2\sum i\,x_{(i)}}{n\sum x_i} - \dfrac{n+1}{n}.

  • Égalité parfaite, x_{(i)} = c : \sum i\,c = c\,\frac{n(n+1)}{2}, d’où G = \frac{n+1}{n} - \frac{n+1}{n} = 0.
  • Un seul individu a tout, x_{(n)} = S : G = \frac{2nS}{nS} - \frac{n+1}{n} = \frac{n-1}{n}, proche de 1.

Décomposition de la variance

g  <- split(x, sal$diplome)
nj <- sapply(g, length)
mj <- sapply(g, mean)
vj <- sapply(g, function(v) mean((v - mean(v))^2))

intra <- sum(nj * vj) / n                # 5010426
inter <- sum(nj * (mj - mean(x))^2) / n  # 1739696
eta2  <- inter / (intra + inter)         # 0.258
Le contrôle à faire

intra + inter doit redonner la variance descriptive totale, 6\,750\,122. Si ce n’est pas le cas, c’est presque toujours que vj a été calculé avec var(), donc en n_j-1 (exercice 3).

Covariance, corrélation, ajustement

Ce qui a demandé treize chapitres tient en une quinzaine de lignes — et c’est bien ainsi. Le semestre n’a jamais servi à apprendre à calculer, mais à savoir ce qu’on calcule et comment le lire.

Un script se relit et se rejoue

Un calcul fait au tableur se perd dans les cellules ; un script se relit, se corrige et se rejoue sur les données de l’année suivante en une seconde. C’est la vraie raison de passer par le code.

S’entraîner

Exercice 1 : n ou n − 1 sur dix salariés

Les dix salariés des chapitres 12 et 13 
x <- c(2, 3, 4, 5, 6, 8, 10, 12, 15, 20)            # années
y <- c(4.5, 5, 6.5, 5.5, 7.5, 6, 8.5, 7.5, 9, 11)   # milliers
var(x)        # 33.38889
cov(x, y)     # 10.77778
cor(x, y)     # 0.9275
  1. Retrouver la variance descriptive V(x) et la covariance descriptive.
  2. Calculer la pente \hat b de deux façons : avec les sorties de R, puis avec les valeurs descriptives. Conclure.
  3. Pourquoi cor() ne demande-t-elle aucune correction ?

Exercice 1 : solution

Le facteur (n − 1)/n = 0,9
  1. V(x) = 0{,}9 \times 33{,}389 = 30{,}05, soit \sigma_x = 5{,}48 ans ; \mathrm{cov} = 0{,}9 \times 10{,}778 = 9{,}70 : les valeurs du chapitre 12.
  2. Avec R : \hat b = 10{,}778/33{,}389 = 0{,}323. En descriptif : 9{,}70/30{,}05 = 0{,}323. La même pente : le facteur 0{,}9 se simplifie.
  3. r = \mathrm{cov}/(\sigma_x\sigma_y) est aussi un rapport : le facteur se simplifie. Seuls les niveaux (variance, écart-type, covariance) dépendent de la convention ; les rapports (r, \hat b, CV, \eta^2) n’en dépendent pas, à condition d’employer la même convention en haut et en bas.

Exercice 2 : la région explique-t-elle le salaire ?

Une sortie de R à exploiter 
> tapply(x, sal$region, mean)
        Autres     Casablanca          Rabat Tanger-Tetouan
      6272.346       7887.445       7504.314       6805.833
> table(sal$region)
        Autres     Casablanca          Rabat Tanger-Tetouan
            81            137            102            180
  1. Calculer la variance inter-régions (moyenne générale 7\,158{,}26).
  2. En déduire \eta^2, sachant que V = 6\,750\,122. Comparer au diplôme (0{,}258).
  3. Écrire en R une fonction eta2(y, g) qui fasse ce calcul.
  4. Casablanca compte 23{,}4\,\% de Bac+5, « Autres » 13{,}6\,\%. Qu’en conclure ?

Exercice 2 : solution

Variance inter et rapport de corrélation
  1. Les écarts à la moyenne générale valent -885{,}9 ; 729{,}2 ; 346{,}1 ; -352{,}4, d’où 81 \times 885{,}9^2 + 137 \times 729{,}2^2 + 102 \times 346{,}1^2 + 180 \times 352{,}4^2 \approx 170{,}99 \text{ millions} V_{\text{inter}} \approx 170{,}99 \times 10^6 / 500 \approx 341\,980
  2. \eta^2 = 341\,980/6\,750\,122 = 0{,}051 : la région explique 5\,\% de la dispersion, cinq fois moins que le diplôme.

Exercice 2 : le code et l’interprétation

Le code et l’effet de structure
  1. Le rapport de la variance inter à la variance totale :
eta2 <- function(y, g) {
  m <- mean(y)
  inter <- sum(tapply(y, g, function(v) length(v) * (mean(v) - m)^2))
  inter / sum((y - m)^2)
}
eta2(x, sal$region)       # 0.0507
  1. Une partie de l’avance de Casablanca vient de sa composition : plus de diplômés. C’est l’effet de structure du chapitre 11 ; comparer les régions à diplôme égal dirait si un écart subsiste.

intra <- sum(nj * vj) / n

Pour chaque ligne : trouver l’erreur, la corriger, et dire ce qu’elle change sur nos données. Pour (d), on voulait les profils-lignes.

Exercice 3 : solution

(a), (b), (c)
    1. Classes ]a\,;\,b] : ajouter right = FALSE. Le salarié à 6\,000 dh passe de la 3e à la 2e classe (157/166 devient 158/165).
    1. Histogramme en effectifs : ajouter freq = FALSE. R affiche un avertissement, mais trace quand même le graphique faux.
    1. Écart-type corrigé, 2\,600{,}70 : écrire sd(...) * sqrt((n-1)/n), ou sdd(), pour 2\,598{,}10.
(d), (e)
    1. Fréquences conjointes : le tableau entier somme à 1. Écrire prop.table(..., 1) pour que chaque ligne somme à 1.
    1. Variances en n_j - 1 : la variance intra devient 5\,043\,703 au lieu de 5\,010\,426, et intra + inter dépasse la variance totale de 33\,277. Le contrôle de la décomposition détecte l’erreur.
