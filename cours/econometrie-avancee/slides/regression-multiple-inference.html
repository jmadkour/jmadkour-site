Où en sommes-nous ?

Les chapitres du cours

Pourquoi ce chapitre ?

Un coefficient estimé n’est jamais nul par hasard, même si le vrai effet est nul — c’est un nombre calculé sur un échantillon particulier. Il faut un cadre statistique rigoureux pour décider si un effet estimé est significativement différent de zéro, et pour quantifier l’incertitude qui l’entoure.

Le modèle linéaire classique

L’hypothèse de normalité

Hypothèse MLR.6 et modèle linéaire classique

En ajoutant à MLR.1–5 l’hypothèse MLR.6 — \(u\mid x_1,\dots,x_k\sim\mathcal{N}(0,\sigma^2)\) —, on obtient le modèle linéaire classique (MLC). Sous ces six hypothèses, les estimateurs MCO sont normalement distribués : \[\hat\beta_j \sim \mathcal{N}\big(\beta_j,\ \operatorname{Var}(\hat\beta_j)\big),\] et, en remplaçant \(\sigma^2\) par son estimation, \(\dfrac{\hat\beta_j-\beta_j}{\operatorname{se}(\hat\beta_j)}\sim t_{n-k-1}\).

Le test de Student

Tester un coefficient

Test \(t\)

Pour tester \(H_0:\beta_j=0\) contre \(H_1:\beta_j\neq0\), la statistique \[t = \dfrac{\hat\beta_j}{\operatorname{se}(\hat\beta_j)}\] suit une loi \(t_{n-k-1}\) sous \(H_0\). On rejette \(H_0\) au seuil \(\alpha\) si \(|t|>t_{\alpha/2,\,n-k-1}\) — le coefficient est alors dit statistiquement significatif au seuil \(\alpha\).

Intervalle de confiance

Un intervalle de confiance à \(100(1-\alpha)\%\) pour \(\beta_j\) est \[\hat\beta_j \pm t_{\alpha/2,\,n-k-1}\ \operatorname{se}(\hat\beta_j).\]

Significativité statistique \(\neq\) importance économique

Un coefficient peut être statistiquement significatif (grand échantillon, faible erreur-type) tout en étant économiquement négligeable — et inversement, un effet important peut manquer de significativité sur un petit échantillon. Toujours interpréter l’ampleur du coefficient, pas seulement son test \(t\).

Le test de Fisher

Tester plusieurs restrictions à la fois

Test \(F\) (restrictions multiples)

Pour tester \(q\) restrictions simultanément (par exemple, \(H_0:\beta_2=\beta_3=\cdots=\beta_{k}=0\), l’exclusion conjointe de plusieurs variables), on compare la somme des carrés des résidus du modèle contraint (\(SSR_r\), imposant \(H_0\)) à celle du modèle non contraint (\(SSR_{ur}\)) : \[F = \dfrac{(SSR_r-SSR_{ur})/q}{SSR_{ur}/(n-k-1)} \ \sim\ F_{q,\,n-k-1} \text{ sous } H_0.\] Plus \(F\) est grand, plus imposer les restrictions dégrade l’ajustement — un argument contre \(H_0\).

Un cas particulier utile : la significativité globale

Tester \(H_0:\beta_1=\cdots=\beta_k=0\) (aucun régresseur n’a d’effet) est le test \(F\) de significativité globale de la régression, rapporté automatiquement par tout logiciel économétrique — un test conjoint qu’aucune suite de tests \(t\) individuels ne peut reproduire correctement (les tests \(t\) ignorent la corrélation entre estimateurs).

Application en finance : tester un modèle factoriel

Pour un modèle multifactoriel (chapitre 1, économétrie financière), le test \(t\) sur chaque \(\hat\beta_{ik}\) indique si l’actif est significativement exposé au facteur \(k\) pris isolément ; le test \(F\) de significativité globale répond à une question différente et plus large : le modèle factoriel dans son ensemble explique-t-il significativement le rendement de l’actif ? On utilise de même un test \(F\) pour tester si un sous-ensemble de facteurs (par exemple, tous les facteurs sectoriels) peut être exclu conjointement du modèle sans perte significative d’ajustement.

Ce qu’il faut retenir

L’essentiel du chapitre 4
  • Sous MLR.1–6 (modèle linéaire classique), \(t=\hat\beta_j/\operatorname{se}(\hat\beta_j)\sim t_{n-k-1}\) sous \(H_0:\beta_j=0\).
  • Intervalle de confiance : \(\hat\beta_j\pm t_{\alpha/2,n-k-1}\operatorname{se}(\hat\beta_j)\).
  • Le test \(F\) teste des restrictions multiples simultanément, y compris la significativité globale du modèle — au-delà de ce que des tests \(t\) isolés peuvent révéler.
