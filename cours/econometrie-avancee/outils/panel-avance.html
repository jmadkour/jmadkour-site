Chapitre 13 — Données de panel : méthodes avancées

Calculatrice interactive — transformation within, paramètre λ (effets aléatoires) et test de Hausman

Transformation within (centrage temporel)

Une valeur par ligne (une série temporelle pour un seul individu).

Paramètre λ des effets aléatoires

Test de Hausman

λ = 0 redonne les MCO groupés, λ = 1 redonne les effets fixes. Pour T = 2, effets fixes et différence première coïncident exactement ; ce n'est plus vrai pour T > 2.
