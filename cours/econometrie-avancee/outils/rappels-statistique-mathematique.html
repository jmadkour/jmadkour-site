Annexe C — Rappels de statistique mathématique

Outils interactifs — erreur quadratique moyenne (biais-variance), intervalle de confiance approché

Comparer deux estimateurs par l'erreur quadratique moyenne (EQM)

EQM(W) = Var(W) + [Biais(W)]². Un estimateur biaisé peut avoir une EQM plus faible qu'un estimateur non biaisé si sa variance est suffisamment réduite.

Intervalle de confiance approché pour une moyenne

Pour n grand, IC ≈ estimation ± 1,96 × erreur-type (le facteur 1,96 se confond avec 2 dès que n dépasse une vingtaine d'observations).

Rappel de l'annexe C : un intervalle de confiance ne signifie pas "95 % de chances que le paramètre soit dedans" une fois l'échantillon observé — c'est une propriété de la procédure répétée, pas une probabilité sur le paramètre lui-même.
