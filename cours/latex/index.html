LaTeX

Informatique — la rédaction scientifique

LaTeX n’est pas un traitement de texte. C’est un langage : vous décrivez ce que vous voulez dire, le logiciel décide de la mise en page. Vous écrivez « ceci est une section », « ceci est une équation » — jamais « ceci est en gras 14 points centré ».

L’effort initial est réel. Le bénéfice l’est aussi : sur un mémoire de cent pages, la numérotation, la table des matières, les renvois et la bibliographie se tiennent tout seuls.

AstuceUn éditeur de formules dans chaque chapitre

Vous tapez à gauche, la formule s’affiche composée à droite, instantanément. Aucune installation, aucune compilation, aucune attente : c’est la façon la plus rapide d’apprendre à écrire des mathématiques.

NotePourquoi commencer par les formules

Parce que c’est là que LaTeX est irremplaçable, et parce que le résultat est immédiat. Un traitement de texte ordinaire compose mal les mathématiques ; LaTeX les compose comme les revues scientifiques, depuis quarante ans.

Les trois premiers chapitres suffisent déjà à rédiger toutes les équations d’un mémoire, même si le texte autour reste écrit ailleurs.

Trois façons de travailler

Voie Pour qui
Overleaf — dans le navigateur, rien à installer débuter, et rédiger à plusieurs
TeX Live — distribution complète, tous systèmes travailler hors ligne, sur la durée
MiKTeX — sous Windows, télécharge les paquets à la demande Windows, installation légère au départ

Commencez par Overleaf. Passez à une installation locale quand le document devient volumineux : la compilation y est plus rapide, et vous ne dépendez plus d’une connexion.
