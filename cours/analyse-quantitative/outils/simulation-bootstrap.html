Chapitre 12 — Simulation et bootstrap

Calculatrice interactive — Analyse quantitative

1. Précision Monte Carlo (erreur en $1/\sqrt{B}$)

2. Simulation par transformation inverse (loi exponentielle)

3. Correction par variable de contrôle

Rappels : erreur Monte Carlo $\propto1/\sqrt{B}$ ; transformation inverse $X=F^{-1}(U)$ ; correction par variable de contrôle $\text{Prix}_{\text{corrigé}}=\text{Prix}_{\text{MC}}-(\text{Contrôle}_{\text{MC}}-\text{Contrôle}_{\text{exact}})$. Le bootstrap ne peut jamais produire une valeur plus extrême que le maximum (ou minimum) observé dans les données.
