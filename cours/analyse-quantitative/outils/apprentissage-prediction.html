3. Coût économique d'un seuil de décision

Rappels : $\Pr(Y=1\mid X)=1/(1+e^{-z})$ avec $z=\beta_0+\sum\beta_jX_j$ ; accuracy $=(VP+VN)/n$, précision $=VP/(VP+FP)$, rappel $=VP/(VP+FN)$, F1 $=2\times\text{précision}\times\text{rappel}/(\text{précision}+\text{rappel})$ ; sur données déséquilibrées, l'accuracy seule est trompeuse ; le seuil optimal minimise le coût économique total, pas le nombre brut d'erreurs.
