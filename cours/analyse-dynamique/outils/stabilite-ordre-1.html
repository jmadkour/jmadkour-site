Chapitre 3 — Stabilité de l'équilibre

Calculatrice interactive — Analyse dynamique

Classer la stabilité, tracer la trajectoire, calculer la demi-vie

Discret : stable si $|a|<1$ ; oscillant si $a<0$. Continu : stable si $a<0$ ; jamais d'oscillation, car $\mathrm{e}^{at}>0$ garde toujours le même signe. Demi-vie : $\tau=\ln(0{,}5)/\ln|a|$ (discret) ou $\tau=\ln(0{,}5)/a$ (continu), définie seulement si le régime est stable.
