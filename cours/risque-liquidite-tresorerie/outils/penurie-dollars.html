Chapitre 15 — Application : la pénurie de dollars dans la banque mondiale

Le coût du financement en dollars via swap de change

Coût implicite en dollars du financement via swap : $i_{\text{swap}}=i_{\text{dom}}+b$, où $b$ est la base de swap de change (cross-currency basis). Coût sur $j$ jours (base 360) : $N\times i\times j/360$. Le nombre de renouvellements sur l'horizon de détention matérialise le risque d'écart de financement du chapitre.

Les lignes de swap de banques centrales

Une banque centrale ne peut pas créer de devise étrangère : sa capacité à répondre seule à une pénurie de dollars est bornée par ses réserves de change $R$. La ligne de swap $L$ s'y ajoute, sans nécessairement combler l'écart $G$. Intérêt sur $j$ jours (base 360) : $L\times i\times j/360$.
