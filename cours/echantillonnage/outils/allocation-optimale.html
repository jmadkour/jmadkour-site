Chapitre 7 — L'allocation optimale et l'effet de plan

Application interactive — Échantillonnage

Calculatrice d'allocation : proportionnelle, Neyman, coûts, égale

Une ligne par strate (six au plus) : taille Nh, moyenne Ȳh ou proportion Ph, écart-type Sh (calculé en Nh − 1), coût ch d'une interview (1 si la case est vide) et, pour comparer sa propre répartition, nh saisi (facultatif). La moyenne Ȳh est facultative : elle sert à reconstituer S² (décomposition intra + inter), donc la variance du sondage aléatoire simple et l'effet de plan. Une strate dont l'allocation dépasserait Nh est recensée (nh = Nh) et le reste est réparti entre les autres. Valeurs par défaut : les quatre provinces de la population du cours, n = 200.

Simuler les allocations dans la population du cours

On stratifie les 2 000 ménages, on répartit n selon chaque allocation (écarts-types Sh de la population, arrondi par la méthode des plus forts restes), puis on tire sans remise dans chaque strate et l'on calcule ȳst = Σ Wh ȳh. Un sondage aléatoire simple de même taille sert de référence. Le générateur de cette page n'est pas celui de numpy : les variances observées diffèrent un peu de celles du chapitre, les variances théoriques sont exactes.

Effet de plan de Kish : ce que coûtent des poids inégaux

Une ligne par groupe d'unités de même poids : nombre d'unités tirées ng et poids dg = Nh/nh. La formule de Kish, 1 + CV² des poids, donne l'effet de plan dû aux seuls poids, lorsque toutes les strates ont la même moyenne et la même dispersion. Si l'on connaît l'effet de plan exact (calculatrice ci-dessus), on peut le saisir pour comparer.

Formules du chapitre : V(ȳst) = Σ Wh² (1 − fh) Sh²/nh = Σ Wh² Sh²/nh − (1/N) Σ Wh Sh². Proportionnelle : nh = n Nh/N. Neyman : nh = n Nh Sh/Σ Nk Sk, de variance S̄²/n − (1/N) Σ Wh Sh² avec S̄ = Σ Wh Sh. Coûts C = c0 + Σ ch nh : nh ∝ Nh Sh/√ch. Égale : nh = n/H. Proportion : Sh² = Nh/(Nh − 1) × Ph(1 − Ph). Effet de plan (Kish) : deff = Vplan/VSAS, VSAS = (1 − n/N) S²/n pour la même taille n ; taille effective neff = n/deff ; deft = √deff. Poids inégaux : deff ≈ 1 + CV²(dk) = n Σ dk²/(Σ dk)².
