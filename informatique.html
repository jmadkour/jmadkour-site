Informatique

Cinq logiciels, expliqués depuis zéro

Cette rubrique enseigne les logiciels eux-mêmes. Une notion, une commande, son résultat. Ce que vous en ferez ensuite vous appartient — et vous le retrouverez dans les cours de licence, de master et de doctorat.

Chaque logiciel a son cours, découpé en chapitres. Il n’y a pas de diapositives : ce sont des livres vivants, où le code s’exécute dans la page, comme dans un carnet de notes.

AstuceVous n’avez rien à installer

Les encadrés de code sont modifiables. Vous changez une valeur, vous cliquez, vous voyez le résultat. Tout se passe dans votre navigateur — aucun compte, aucun logiciel, aucune donnée envoyée nulle part.

Par où commencer

Aucun de ces cours ne suppose de connaissance préalable. Ils se lisent dans n’importe quel ordre.

Si vous voulez… Ouvrez
calculer, résoudre des systèmes, manipuler des matrices MATLAB
un langage utile bien au-delà des études Python
faire de la statistique et des graphiques soignés R
rédiger un mémoire propre, avec des formules LaTeX
cliquer plutôt que taper EViews
Note

MATLAB, Python et R font en grande partie les mêmes choses. Le premier appris demande un effort ; les suivants s’apprennent bien plus vite, parce que les idées se ressemblent.

Comment ces cours fonctionnent

Cours Exécution du code
Python, R dans la page ; le langage se charge au premier clic, puis reste en mémoire
LaTeX vous tapez la formule à gauche, elle s’affiche composée à droite
MATLAB un bouton ouvre le script dans MATLAB Online ou dans Octave Online
EViews logiciel à fenêtres, sans version navigateur : montré écran par écran

Le tout premier lancement de Python ou de R prend une dizaine de secondes, le temps de télécharger le langage. Ensuite, les exécutions sont instantanées.
