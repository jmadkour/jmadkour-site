% a single info line with optional right-aligned date, own longtable per call for simplicity avoided;
% instead we use a shared longtable environment: cvlist
% L'interligne des rubriques est fixe explicitement. Le PDF d'origine, compose
% par LuaTeX, espacait les lignes de 21,1 pt ; le comportement par defaut en
% donne 14,2. Le facteur ci-dessous retablit ce pas, quel que soit le moteur.
% La colonne de gauche prend tout ce que laisse la colonne de date (largeur
% fixe, les dates n'ayant pas besoin de plus) : le tableau remplit \textwidth
% quels que soient les réglages de geometry, sans largeur à recalculer à la main.
\newenvironment{cvlist}{%
  \renewcommand{\arraystretch}{1.486}%
  \begin{longtable}{@{}L{\dimexpr\textwidth-2.9cm-4mm\relax}@{\hspace{4mm}}R{2.9cm}@{}}
}{%
  \end{longtable}
}
